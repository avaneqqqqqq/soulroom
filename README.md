# soulroom

Музыкальный плеер для Windows: Яндекс.Музыка, SoundCloud, Spotify и свои аудиофайлы в одном пространстве.

## Установка

Скачай **soulroom-0.2.0-setup.exe** в [Releases](https://github.com/avaneqqqqqq/soulroom/releases/latest). Установи и открой soulroom. Аккаунты подключаются в разделе «Источники и настройки».

## Возможности

- «Моя волна», станции жанров и настроений, загрузка рекомендаций при открытии.
- Избранное с фильтром по источникам, свои плейлисты и перенос из сервисов.
- Большой экран «Сейчас играет», тексты с подсветкой и перемоткой по строке при наличии таймингов, импорт LRC.
- Подбор клипов YouTube и синхронизация видео со звуком, настройка сдвига.
- Эквалайзер в нижнем баре: десять полос, пресеты, АЧХ, стерео и запас по уровню.
- Восемь тем, настройка цвета, шрифта, размера текста, плотности и обложек.
- Очередь, быстрые команды Ctrl+K, таймер сна.

SoundCloud предлагает прямое подключение и резервные маршруты; доступность зависит от сети. Spotify используется для каталога и сохранённой музыки: полное воспроизведение Spotify через этот плеер не предоставляется. Для импорта закрытых плейлистов нужны соответствующие права аккаунта. Автовход Яндекса и SoundCloud работает в десктопном приложении; браузерная версия не читает сессии в других вкладках.

## Обновления

Приложение проверяет стабильные GitHub Releases после запуска и каждые четыре часа. Новая версия появляется в уведомлении сверху: **Загрузить → Установить и перезапустить**. Загрузка показывает прогресс; electron-updater проверяет контрольную сумму из latest.yml. Загрузка и установка не запускаются без нажатия. Кнопка ручной проверки есть в настройках. Настройки и аккаунты установленного приложения хранятся в пользовательском профиле и не включаются в установщик.

Для обновления с запуска из исходников впервые установи готовую версию. Повторный запуск исходников через start.cmd не заменяет установленное приложение.

## Запуск из исходников

Нужны Node.js 24 и Windows x64.

```powershell
npm ci
npm run desktop
```

start.cmd запускает десктоп; start-web.cmd — локальный веб-интерфейс без десктопного захвата сессий.

## Сборка и выпуск

```powershell
npm run test:release
npm run dist:win
```

Результат в release/: установщик, блок-карта и latest.yml. GitHub Actions собирает Windows при теге vX.Y.Z и создаёт черновик релиза. После проверки установщика опубликуй черновик: тогда клиенты увидят версию. Публиковать нужно все три файла вместе. Обычным пользователям GitHub-токен не нужен.

Локальная публикация: npm run release:win с GH_TOKEN в окружении. Токен никогда не включается в исходники, установщик или настройки клиента. В CI используется встроенный GITHUB_TOKEN с правом contents:write. Для подписания Windows-сборок издателю понадобится свой сертификат подписи; по умолчанию сборка не подписана.

## Ограничения проверки

Регрессии обновлятора, таймингов, эквалайзера, OAuth и плейлистов покрыты изолированными тестами. Реальный переход между двумя установленными версиями и доступ к личным библиотекам требуют проверки с выпущенными сборками и аккаунтами. Тексты/клипы зависят от наличия меток и доступности внешних источников.
