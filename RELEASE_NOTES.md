Обновление плеера soulroom для Windows x64.

- Ускорен старт SoundCloud: прогрессивный MP3 и совместимый HLS начинают отдаваться до полной загрузки. Следующий трек готовится заранее, готовое аудио кешируется.
- Главная страница и меню настроений используют волну из источника по умолчанию или выбранной смеси сервисов. Обложки подборок берутся из рекомендаций и меняются при запуске.
- Кнопка «Включить» открывает выбор настроения или жанра. Волна дозагружается при прокрутке, без кнопки «Ещё рекомендации».
- Настройки подключения хранятся в постоянном профиле, записываются через временный файл и имеют резервную копию.
- Исправлено включение обработки при изменении EQ и обход режима сравнения. Добавлены скорость, сохранение высоты тона, Slowed/Nightcore/Lo-Fi/Vaporwave, глубина, реверберация и мягкая компрессия.
- Восстановлен доступ к большому плееру по обложке, названию текущей песни и кнопке сверху. Добавлена загрузка обложек через локальный сервер и запасной рисунок при ошибке сети. Исправлено положение сердца.
- Клипы автоматически сопоставляются по артисту, названию и длительности. Добавлен поиск PeerTube; у YouTube скрыта панель управления в пределах его API. Служебные оверлеи и обозначения YouTube могут оставаться.
- Обновления приходят из этого GitHub: уведомление сверху, прогресс загрузки и установка после нажатия. Проверка версии работает и при исчерпанном анонимном лимите GitHub API.

Для первого перехода с исходников установи setup.exe. Будущие обновления установленного приложения используют постоянный профиль. Установщик пока без цифровой подписи Windows.

Spotify предоставляет каталог и сохранённую музыку, а не полное воспроизведение. Доступность закрытых библиотек, видео, текстов с метками и аудио зависит от аккаунтов и сети. Живые пользовательские аккаунты и слуховая оценка эффектов требуют проверки пользователем.
