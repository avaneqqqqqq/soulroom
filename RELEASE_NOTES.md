В «Моей волне» появилось новое окно выбора станции с категориями, поиском по всем жанрам и отметкой текущей станции. Обновление волны показывает первую доступную подборку и заранее готовит следующую.

Поиск показывает ответы сервисов по мере готовности. Исправлена загрузка аудио Яндекса через резервные адреса API и медиасерверов. При ошибке системного прокси окно входа Яндекса повторяет запрос напрямую.

Режимы эквалайзера используют частотные кривые labsoul. Возврат в «Студию» восстанавливает ручные настройки. Встроенные записи soulroom sessions удалены. Личные лайки дополнительно сохраняются в файле профиля и восстанавливаются при потере браузерной копии.
